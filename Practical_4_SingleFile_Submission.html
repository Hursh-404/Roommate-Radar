NodeJS Server-Side Validation Pipeline (CO3)

Client-side validation is easily bypassed using Developer Tools, cURL, or Postman. The server-side pipeline is the authoritative security boundary:

HTTP Request (POST /api/roommates)
  ↓
1. Payload Stream Accumulator (Enforces 1 MB body size cap)
  ↓
2. JSON Syntax Parser (Catches syntax exceptions safely)
  ↓
3. Sanitizer Engine (Converts <, >, &, " to HTML entities to prevent XSS)
  ↓
4. Modular Validator (validator.js)
    ├─ If errors: Returns HTTP 400 Bad Request + structured error object
    └─ If valid: Commits to DataStore and returns HTTP 201 Created
